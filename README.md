# 印纹试产的留样与放行

经营演练资料均为合成数据，不涉及真实参赛者、顾客或合作方。 `data/drill.json` 为 UTF-8 JSON；顶层键为来源表名，值为行数组。日期按当地工作日历，编号是代号而非名称。 金额使用整数分；`null` 表示未取得该事实，不等于零。

`sheet` 为坯料片，`run` 为独立开机记录，同片的分样试制可跨工艺。`operation=1` 是原加工，后续序号记录同件样品的返工或换料复查；`repetition` 是同次工序重复测量，不是独立件。`contrast` 为 0 到 100 的仪表对比度。`aging.result` 的空值另按到期日判断；`permission` 记录放行决定采用的检验证据，`sent_to` 非空代表柜台已经收到。试验机时用整小时计。

## 资料预检

使用 Python 3.11 或更高版本，无第三方依赖。 在项目根目录运行 `python3 -m unittest discover -s tests -v` 核对演练资料的表结构、事实关联及业务场景所需的原始记录。

## 统一分析入口 `bookmark_qc`

全部过程记录、实物分流、量检重复测量、留样与到期结果读进同一个 `Project`（`python3 -m bookmark_qc --data data/drill.json <子命令>`），装载时完成表结构、外键与业务前提预检。子命令：

| 子命令 | 回答的问题 | 关键口径 |
| --- | --- | --- |
| `process` | 改压与标准工艺的差异能否归因于工艺 | 独立单元是**开机**而非同片十件样品；重复测量先在样品内取均值。只有同片材料上两工艺各有一次分样试制开机才构成配对；材料只在单一工艺出现的（批次×纹路）格子标记为无支持，不参与归因。分样试制与正常试产分开统计 |
| `rework` | 同件原样返工复查是工艺改善、换料掩盖还是仍无法区分 | 只换工艺且批次不变→工艺改善；只换批次→换料掩盖问题；工艺与批次同时变化→仍无法区分；两者都没变→不构成新证据 |
| `aging` | 老化复查当前处于什么状态 | 未到期、成熟合格、成熟不合格、留样失联、逾期未检（已到期无结论，是缺口不是合格）分别显示；结论适用范围按批次×纹路给出 |
| `release` | 批次级异常后哪些款暂停、哪些不受影响、追查范围到哪 | 共享试产证据链上的放行单全部进入保留；独立复验不被自动推翻（自身留样成熟不合格除外）。已交付柜台的只列追查范围，原始 `sent_to` 不回填；纹路/工艺与留样事实不一致的放行单给适用范围警告 |
| `planning` | 一周内重新开卖，剩余留样该用于定位缺陷还是验证恢复销售 | 枚举全部可行方案并标注路线（批次归因/复验放行）、排期、消耗留样与能解除的保留。消耗性试验一旦确认，同件留样的其他方案关闭；机时按窗口内容量顺排，窗口外机时单列；纹路不匹配的复验不能真正解除该款保留，仍列入不可推断名单 |
| `ingest` | 新复查结果改变了哪条判断、哪张旧放行单要通知 | 增量老化结论/批次异常/返工读数从同一入口进入，返回不可变的新项目与变化报告；通知分已交付追查、未交付暂停、仅通知（独立复验）三类，并列出仍不能推断能否销售的款 |
| `board` | 一页式总览 | 串联以上全部视图 |

每个子命令加 `--json` 输出机器可读结果（`--json` 与 `--as-of YYYY-MM-DD` 写在子命令前后均可）。`ingest --updates <文件>` 接收含 `aging`/`recheck`/`readings` 三个数组的增量 JSON，缺省数组视为空。

### 看板日

老化与规划默认以最近一次批次级异常的发现日为看板日（本资料为 2026-07-26），可用 `--as-of` 覆盖。状态判定：失联单列；已取得检查结论（含提前复查）以结论为准；无结论时到期日晚于看板日为未到期，已到期为逾期未检。

### 规划窗口

“一周内重新开卖”的自然截止日为看板日 +7 天；`window` 给出窗口内实际登记了机时容量的末日，`window_deadline` 给出自然截止日，`out_of_window_capacity` 单列一周之外的机时，不参与本次方案。

## 代码布局

```
bookmark_qc/
  model.py     数据模型、装载与资料预检
  process.py   共同材料配对的工艺对比、证据类型区分
  rework.py    同件原样返工/换料复查判读
  aging.py     老化看板与批次×纹路适用范围
  release.py   证据链还原、批次异常后的保留与追查
  planning.py  机时/留样约束下的方案枚举与保留解除
  ingest.py    新复查结果入口与判断变化追踪
  cli.py       统一命令行入口
tests/         原始资料核查 + 各模块业务规则测试（38 个用例）
```
